# Tots frontend

React/Vite client for the Tots anonymous chat application.

## Development

Start the backend on port 5000, then run:

```sh
npm install
npm run dev
```

Localhost automatically connects to `http://localhost:5000`. Override the
Socket.IO server in any environment with `VITE_SOCKET_URL`.

## Checks

```sh
npm run lint
npm run build
```
